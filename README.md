🧠 NeuroRead – Cognitive Text Intelligence Platform

## 📖 Description
NeuroRead is an advanced web-based cognitive text analysis platform that evaluates reading material (PDF, DOCX, TXT) and visualizes cognitive load.

## 🏗 Repository Structure
- `src/backend/` - FastAPI REST API & Document Parsers
- `src/ai_engine/` - SpaCy NLP, ChromaDB RAG & Ollama/Instructor LLM
- `src/frontend/` - React Dashboard, Heatmap & Visualizer UI
- `docs/` - SRS, Design Documents & UML Diagrams
